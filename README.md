One line, 143 characters, written to make the judge fall in love with a person caught in a small, specific detail:

> "My grandmother kept every letter my grandfather wrote; I finally understand why, because I'd keep a grocery list if your handwriting was on it."

## Run it

```sh
python3 main.py
```

This writes the line, exactly and with no trailing newline, to `/output/entry.txt`. Deterministic, standard library only, no network.
